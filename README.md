# Первооткрыватели Прикамья

Интерактивный портал технической документации и архитектуры проекта **«Первооткрыватели Прикамья»** — AR-квеста по историческим дорогам Пермского края.

## Разделы портала

- **01. Обзор системы** — цели механики квеста, глоссарий, пользователи, технологический стек и интерактивная схема архитектуры.
- **02. 11 архитектурных контуров** — клиентское представление (Unity + Vuforia, Refine + Storybook), BFF Directus + AtomicCMS, доменные сервисы (Workers + Temporal + Dify), NATS JetStream, PostgreSQL 17 + PostGIS, Garage S3, RBAC, AR/3D-пайплайн, Forgejo + Verdaccio + Docusaurus, наблюдаемость и интеграция с мероприятиями.
- **03–04. DDD-карта и модель данных** — ограниченные контексты, формат событий `QuestCompleted`, структура 7 коллекций Directus (`characters`, `question_sets`, `calendar_plans`, `quest_attempts`, `achievements`, `invitations`, `visits`) и ограничения целостности.
- **05–06. API-контракты и RBAC-матрица** — интерактивная проверка REST-эндпоинтов по ролям (`Guest`, `User`, `Content Manager`, `Event Manager`, `Admin`), стримы NATS, коды ошибок и матрица прав доступа.
- **07–08. Развёртывание и онбординг** — конфигурация WSL2, Docker Compose, локальные endpoint'ы, миграции БД и Forgejo Actions CI.
- **09–10. Руководства и симулятор** — инструкции пользователя и администраторов, а также интерактивный симулятор AR-квеста («Ноябрь — Витус Беринг») и сканер погашения QR-приглашений.
- **11. Эксплуатация и мониторинг** — SLO, проверки сервисов, политика резервного копирования и матрица эскалации P1–P3.
- **12. Расширенный стек и ADR-01** — интеграция `Traefik`, `Zod`, `Temporal`, `Dify`, `AtomicCMS`, `Docusaurus`, `Storybook`, live-валидатор схем Zod и архитектурная оценка применимости `EmDash`.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка сборки и типов:

```bash
npm run lint
npm run build
```
